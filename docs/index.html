How it works & privacy

Your lockfile is parsed by JavaScript on this page and never uploaded. To look up vulnerabilities, the page sends only package names and versions (e.g. rails 7.1.3) straight from your browser to OSV.dev, Google's free, open vulnerability database that aggregates GitHub Security Advisories, PyPA, RustSec, Go and others. Severity comes from the advisory (or its CVSS score). "Fixed in" is the earliest fixed version OSV lists. Server versions (nginx, Java) are only compared on this page. The site has no backend and no analytics cookies.

Limits: only what's in your lockfile is checked (not your OS packages or containers), and OSV can lag a few days behind a disclosure. When in doubt, follow the vendor advisory.
